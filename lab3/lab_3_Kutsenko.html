Хід роботи¶

Завдання¶

Виконати теоретичні розрахунки асимптотичної складності алгоритмів сортування методами вставляння та бульбашки.

Реалізувати на Python алгоритм сортування методом бульбашки.

Дослідити реальний час виконання обох алгоритмів на Python і побудувати графіки залежностей 𝑇𝑖𝑛𝑠𝑒𝑟𝑡(𝑛) та 𝑇𝑏𝑢𝑏𝑙𝑒(𝑛) для 𝑛 = [5, 10,50,100,500,1000,2000,3000,4000,5000,10000,20000,50000,10000], згенерувавши відповідні цілочисельні масиви.

Виконання¶

Сортування вставлянням має асимптотичну складність O(n^2), оскільки для кожного елемента масиву може виконуватися до n порівнянь і зсувів. Сортування бульбашкою також має складність O(n^2), тому що використовує два вкладені цикли, які проходять по всьому масиву. У найгіршому випадку кількість операцій пропорційна n².

import random
import time

# 2. Алгоритми сортування
def insertion_sort(nums):
    for j in range(1, len(nums)):
        key = nums[j]
        i = j - 1
        while i >= 0 and nums[i] > key:
            nums[i + 1] = nums[i]
            i -= 1
        nums[i + 1] = key

def bubble_sort(nums):
    n = len(nums)
    for i in range(n):
        for j in range(0, n - i - 1):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]

# 3. Тестування
sizes = [5, 10, 50, 100, 500, 1000, 2000, 3000, 4000, 5000]
times_insert = []
times_bubble = []

for n in sizes:
    arr = [random.randint(0, 10000) for _ in range(n)]
    
    # Замір Insertion Sort
    arr_c1 = arr.copy()
    start = time.time()
    insertion_sort(arr_c1)
    times_insert.append(time.time() - start)
    
    # Замір Bubble Sort
    arr_c2 = arr.copy()
    start = time.time()
    bubble_sort(arr_c2)
    times_bubble.append(time.time() - start)

# 4. Графік
plt.figure(figsize=(10, 6))
plt.plot(sizes, times_insert, label="Insertion Sort", marker='o')
plt.plot(sizes, times_bubble, label="Bubble Sort", marker='s')
plt.xlabel("Розмір масиву (n)")
plt.ylabel("Час (секунди)")
plt.title("Порівняння алгоритмів сортування")
plt.legend()
plt.grid(True)
plt.show()

Висновок¶

Обидва алгоритми мають складність O(n^2), але на практиці сортування вставлянням працює швидше за бульбашкове сортування. Зі збільшенням розміру масиву час виконання значно зростає.

Контрольні питання¶

1. Що таке O-нотація і чим вона відрізняється від Ω-нотації?¶

O-нотація (Big-O) описує асимптотичну верхню межу складності алгоритму, тобто показує найгірший випадок зростання часу виконання. Ω-нотація (Big-Omega) описує асимптотичну нижню межу складності алгоритму, тобто показує найкращий можливий випадок. Основна різниця: O-нотація — це верхня оцінка, Ω-нотація — нижня.

2. Яку часову складність має алгоритм сортування методом вставляння за найсприятливіших умов?¶

У найкращому випадку масив вже відсортований.
Тоді кожен елемент перевіряється лише один раз без зсувів. Отже, алгоритм виконує лінійний прохід по масиву. Часова складність: O(n).

3. Визначення ефективного алгоритму¶

Ефективний алгоритм — це алгоритм, який виконує задачу з мінімальними витратами часу та пам’яті, тобто має оптимальну асимптотичну складність для даної задачі.

4. Поняття головного параметра (розміру) задачі¶

Головний параметр задачі — це величина, яка визначає вхідні дані алгоритму і впливає на його складність. Зазвичай це:

  • кількість елементів масиву (n)
  • розмір графа (вершини/ребра)
  • довжина рядка тощо

5. Асимптотична складність функції F(N)¶

F(N) = N³ + 7N² − 14N Найшвидше зростаючий член — N³, тому він визначає складність. Асимптотична складність: O(N³)
